# pm-jev

Typed, local-first decisions for [pm-cli](https://github.com/unbraind/pm-cli) items, built on
Jev-style System One decision models: a local Ollama model (`tev1`, `nimble`) by default, or
TypeSafe's hosted Jev through the official `@typesafe-ai/sdk`.

Status: in development, not yet released.
